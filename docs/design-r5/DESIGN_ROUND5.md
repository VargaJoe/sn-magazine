# SN Magazine — R5 Fotel-only (Iris)

**Joe pivot:** ne egyszerre. Először csak FotelVándor. Manga hold.  
**Baseline:** korábbi ügynök design (narancs accent, wordmark, top nav, full-bleed fotel-hero, floating fehér card, ikon-nav, kiemelt utazások coverrel, tematikus gyűjtemények, legfrissebb).  
**Nem** R1–R4 lit/cinema/neon vonal.

## Átvéve a baseline-ból
- Narancs `#E87A2E` + charcoal `#2B3544` + fehér card / soft bg
- Top nav (Főoldal / Filmek / Könyvek / Játékkönyvek) + kereső
- Wordmark: `Fotel` + narancs `Vándor` + fotel ikon + tagline
- Full-bleed hero (fotel/olvasás still) + fehér tipó balra
- Floating fehér content card árnyékkal
- Kör ikon-nav (Film / Könyv / Játékkönyv / …)
- Kiemelt utazás-kártyák **cover képpel**
- Tematikus gyűjtemény thumb-sor
- Legfrissebb kalandok list + CTA

## Igazítva (Ada IA lock)
- Hero = **kiemelt esszé fold** (kép-first + meta chipsek + Teljes esszé)
- Nav + ikonok: **Visszatekintés / Archívum** bejárat
- Erős **Van mit olvasni → Visszatekintés** CTA blokk
- **Hírek demoted** (dashed, oldalsáv, nem fold)
- Sorozat kategória opcionálisan bent
- R4 tanulság: cover/still a hero + kártyákon (stock placeholder, jelölve)
